# PomodoroBar

Помодоро-таймер для macOS, который живёт в строке меню и показывает оставшееся время, например `🍅 18:42` на работе и `☕ 04:10` на перерыве.

## Запуск

Нужны macOS 13 или новее и Xcode 15 или новее.

Быстрый запуск для проверки (без системных уведомлений, только звук):

```sh
swift run
```

Установить в «Программы» (один раз, и после каждого обновления кода):

```sh
./scripts/build-app.sh --install
```

Дальше PomodoroBar запускается как обычное приложение: из Launchpad, Spotlight (⌘ пробел → PomodoroBar) или Dock. В настройках можно включить «Запускать при входе в систему».

## Что умеет

- Работа, короткий и длинный перерыв по циклу (по умолчанию 25 / 5 / 15, длинный после 4 помодоро)
- Старт, пауза, сброс, пропуск фазы
- Окно настроек: длительности, число помодоро до длинного перерыва, автостарт, звук
- Звук и уведомление в конце интервала
- Главное окно при запуске: таймер с кольцом прогресса, задачи, настройки
- Список задач с чекбоксами, текущая задача, помодоро на задачу и за сегодня
- Музыка для фокуса: плейлист Spotify в окне и кнопка «Открыть в Spotify», по желанию автозапуск при старте фокуса
- Иконка приложения (исходник: `scripts/assets/AppIcon.svg`)

Закрытое окно можно вернуть из панели в строке меню: «Открыть окно».
