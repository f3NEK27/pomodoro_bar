# PomodoroBar

Помодоро-таймер для macOS, который живёт в строке меню и показывает оставшееся время, например `🍅 18:42`.

## Запуск

Нужны macOS 13 или новее и Xcode 15 или новее.

Из терминала:

```sh
swift run
```

Или в Xcode: File → Open… → выбрать папку проекта (Package.swift) → Run (⌘R).

После запуска справа в строке меню появится `🍅 25:00`. По клику открывается панель со Старт, Пауза, Сброс и Выйти.
